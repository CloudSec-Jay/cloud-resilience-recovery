# Recovery evidence

Use `recovery-test-template.json` as the schema for a sanitized drill record. Do not treat the example timestamps as completed test evidence.

Public evidence may include:

- approved RTO and RPO targets;
- sanitized timestamps and measured durations;
- commit, workflow run, stack version, and ticket references;
- validation outcome and named test method;
- cleanup confirmation;
- gaps, owners, and follow-up dates.

Keep complete ARNs, account IDs, hostnames, customer data, raw filesystem contents, credentials, and unredacted logs in an approved protected evidence store.
