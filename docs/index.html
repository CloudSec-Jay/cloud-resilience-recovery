THE RECOVERY LOOP

Five events. One defensible result.

The record follows the recovery path end to end. Passing requires both the objective and workload validation—not merely an AWS job status.

  1. 01

    Declare

    Start the RTO clock with a timezone-aware incident timestamp.

  2. 02

    Select

    Choose a recovery point and measure its age against RPO.

  3. 03

    Restore

    Create a separate EBS resource in an isolated test scope.

  4. 04

    Validate

    Run workload-specific integrity and usability checks.

  5. 05

    Decide

    Calculate the result and retain a sanitized evidence reference.
